# City-Services-AI-Assistant

## Description 
This project is an AI-powered city services assistant that helps users in the San Antonio area identify where to report problems that you would find within the city to the correct city service department. The application uses Google Gemini as the AI to analyze inputted statements from the user and then provides a response of the correct department that the issue should be reported to based on the city service data that is provided within the system.  

## Features
- Streamlit Web Interface
- Gemini AI integration
- City Services datset lookup

## Requirements 
Install dependencies: 
pip install -r requirements.txt

## Run the application 
streamlit run app.py
